# Password Strength Checker System (SEN 201)

The Password Strength Checker System is a Python-based console application developed as part of the SEN 201 assignment. The system evaluates the strength of a user’s password based on predefined security criteria.

## SOFTWARE DEVELOPMENT LIFE CYCLE (SDLC)

### Stage 1: Requirement Identification  
The objective of this project was to develop a system capable of assessing password strength. The system was required to:
- Accept a password from the user.
- Analyze the password based on length and character composition.
- Classify the password as Weak, Moderate, or Strong.

---

### Stage 2: Application Structure Planning  
The application was planned as a simple command-line Python program. A dedicated function was designed to handle password analysis, while a main function manages user input and output display.

---

### Stage 3: Program Development  
The system was implemented using Python. Built-in string methods were used to check for uppercase letters, lowercase letters, digits, and special characters. Conditional logic was applied to determine the final password strength level.

---

### Stage 4: Verification and Validation  
The application was tested by:
- Entering short passwords to confirm weak strength detection.
- Using mixed-character passwords to validate moderate strength classification.
- Testing complex passwords to ensure strong classification accuracy.

---

### Stage 5: Release and Submission  
The completed program was uploaded to a public GitHub repository as a Python file. The repository serves as the deployment platform for submission and academic evaluation.
